# Mini-Rift: Mitos & Leyendas

MOBA 3D inspirado en mitologías griega y nórdica, construido con HTML, CSS, JavaScript y Three.js.

## Campeones

- **Artemisa — Tirador:** atacantes a distancia y gran precisión.
- **Ares — Luchador:** daño sostenido y supervivencia.
- **Hades — Mago:** daño mágico de gran alcance.
- **Atenea — Tanque:** vida alta y escudo protector.
- **Loki — Asesino:** alta movilidad y daño explosivo.

## Controles

- Click izquierdo/derecho: movimiento
- Q/W/E/R: habilidades
- S: detener

## Ejecutar

```bash
python -m http.server 8080
```

Abrir `http://localhost:8080`.
